# PRD: Switch Editorial Blurbs from Gemini to Claude
**ID:** U-01  
**Status:** Ready to build  
**Priority:** High  
**Effort:** ~1 hour  
**Last updated:** 2026-04-01

---

## Problem
Editorial blurbs in the daily digest are currently generated by Gemini, whose voice drifts toward generic marketing copy — vague, hyped, and lacking the opinionated solo-founder tone the VaiBReport brand targets. Claude Sonnet 4.6 is already used elsewhere in the stack and produces tighter, drier, more opinionated output.

## Goal
Replace the Gemini API call in `generateEditorialBlurbs()` inside `generate-digest.yml` with a Claude Sonnet 4.6 call that produces blurbs matching the voice target: casual dry humor, opinionated solo-founder, direct, no hype. Cost stays under $0.01/day. Existing fallback and output contract are preserved exactly.

## Success Metrics
- Zero digest failures attributable to the API swap on the first 7 post-deploy runs
- Blurb output matches the existing JSON contract (`{"owner/repo": "one-liner blurb"}`) with no downstream breakage
- Subjective voice assessment: blurbs feel more direct and opinionated compared to a Gemini baseline sample
- Cost stays below $0.01/day (verifiable via Anthropic dashboard)

## Scope
### In
- Replace the Gemini API call in `generateEditorialBlurbs()` in `.github/workflows/generate-digest.yml`
- Use model `claude-sonnet-4-6` via the Anthropic Messages API (`POST /v1/messages`)
- Read `ANTHROPIC_API_KEY` from GitHub secrets (already stored)
- Preserve the identical JSON output format: `{"owner/repo": "one-liner blurb"}`
- Preserve the existing fallback: if the API key is missing or the API call fails for any reason, fall back to the existing template blurb — no digest failure
- Update the system prompt to encode the voice target explicitly

### Out
- No changes to blurb rendering, display, or downstream consumers
- No A/B testing or blurb comparison tooling
- No changes to the fallback template content itself
- No streaming — single synchronous call per digest run is fine at this volume

## Technical Spec

### Workflow File
File: `.github/workflows/generate-digest.yml`  
Function: `generateEditorialBlurbs()`

### API Call Replacement
Remove the `@google/generative-ai` or `axios`-based Gemini call. Replace with a Node.js `fetch` call (Node 20 native) to the Anthropic API:

```javascript
const response = await fetch('https://api.anthropic.com/v1/messages', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.ANTHROPIC_API_KEY,
    'anthropic-version': '2023-06-01',
    'content-type': 'application/json',
  },
  body: JSON.stringify({
    model: 'claude-sonnet-4-6',
    max_tokens: 600,
    system: SYSTEM_PROMPT,
    messages: [{ role: 'user', content: userPrompt }],
  }),
});
const data = await response.json();
const blurbs = JSON.parse(data.content[0].text);
```

### System Prompt
```
You write one-liner editorial blurbs for a daily GitHub digest aimed at solo founders and small startup teams. Voice: casual dry humor, opinionated, direct, no hype, no adjective stacking. Each blurb is a single sentence under 20 words. Output valid JSON only: {"owner/repo": "blurb"}.
```

### Fallback Logic
Wrap the API call in try/catch. On any error (missing key, HTTP error, JSON parse failure), log a warning and return the existing template blurbs. Do not throw.

### Token Estimate
~2000 tokens in / ~500 tokens out per digest run. At claude-sonnet-4-6 pricing this is well under $0.01/day.

### Environment
- `ANTHROPIC_API_KEY` — already present in GitHub repo secrets, no new secret needed
- Remove any Gemini-specific secret references if they are no longer used elsewhere in the workflow
